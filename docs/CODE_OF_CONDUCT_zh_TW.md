# 行為準則

[English](CODE_OF_CONDUCT.md) | [简体中文](CODE_OF_CONDUCT_zh.md) | 繁體中文 | [日本語](CODE_OF_CONDUCT_ja.md)

## 我們的承諾

身為參與者、貢獻者與維護者，我們承諾讓每個人都能無騷擾地參與本專案，不因年齡、體型、可見或不可見的障礙、族裔、性徵、性別認同與表達、經驗程度、教育程度、社會經濟地位、國籍、外貌、種族、宗教或性傾向而受到差別對待。

我們承諾以開放、友善、多元、包容、健康的方式行動與交流。

## 我們的標準

有助於營造正向環境的行為：

- 對他人展現同理心與善意
- 尊重不同的意見、觀點與經歷
- 給予並坦然接受建設性回饋
- 承擔責任、向受影響的人道歉，並從經驗中學習
- 以社群與專案的整體利益為重

不可接受的行為：

- 使用性化語言或圖像，以及任何形式的性關注或挑逗
- 嘲諷、侮辱或貶損性評論，以及人身或政治攻擊
- 公開或私下的騷擾
- 未經明確許可發布他人的私人資訊，如住址或電子郵件
- 其他在職業場合中可合理認為不當的行為

## 適用範圍

本準則適用於所有專案空間——issue、pull request、討論、提交訊息與審查——也適用於個人在公共場合正式代表本專案的情形。

## 檢舉與處理

如果你經歷或目睹了不可接受的行為，請透過私密管道告知維護者：使用 [Security 頁籤](https://github.com/EndlessPixel-Studio/FakePlayer-CE/security) 提交私密回報，或在 GitHub 上直接聯絡維護者。請不要開公開 issue 點名當事人。

所有檢舉都會被及時、公正地審查與調查。維護者有義務尊重檢舉人的隱私與安全。

處理方式分四級：

1. **糾正** —— 私下說明問題所在與期望行為，必要時要求公開致歉。
2. **警告** —— 警告並說明繼續該行為的後果，包括一段時間內不得與相關人員互動。
3. **暫時停權** —— 在一段時間內禁止參與社群的任何互動或公開交流。
4. **永久停權** —— 永久禁止參與社群內的任何公開互動。

維護者有權刪除、編輯或拒絕不符合本準則的評論、提交、程式碼、issue 及其他貢獻，並在適當時說明處理理由。
