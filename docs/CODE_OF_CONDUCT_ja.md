# 行動規範

[English](CODE_OF_CONDUCT.md) | [简体中文](CODE_OF_CONDUCT_zh.md) | [繁體中文](CODE_OF_CONDUCT_zh_TW.md) | 日本語

## 私たちの誓い

メンバー、コントリビューター、メンテナとして、年齢、体格、見える・見えない障害、民族、性徴、性自認と表現、経験の程度、教育、社会経済的地位、国籍、外見、人種、宗教、性的指向にかかわらず、誰もがハラスメントなくこのプロジェクトに参加できることを約束します。

私たちは、オープンで歓迎的、多様で包摂的、健全な方法で行動し交流することを約束します。

## 私たちの基準

前向きな環境につながる行動：

- 相手への共感と思いやりを示す
- 異なる意見、視点、経験を尊重する
- 建設的なフィードバックを与え、また快く受け取る
- 責任を受け入れ、影響を受けた人に謝罪し、そこから学ぶ
- コミュニティとプロジェクト全体にとって最善のことを優先する

受け入れられない行動：

- 性的な言葉や画像の使用、あらゆる種類の性的な注目や誘い
- 煽り、侮辱的・中傷的なコメント、個人的または政治的な攻撃
- 公的または私的なハラスメント
- 明示的な許可なく他者の私的情報（住所やメールアドレスなど）を公開する
- 職業的な場面で不適切と合理的に判断されるその他の行動

## 適用範囲

本規範は、issue、pull request、ディスカッション、コミットメッセージ、レビューといったすべてのプロジェクト空間に適用され、個人が公の場で本プロジェクトを正式に代表する場合にも適用されます。

## 報告と対応

受け入れられない行動を経験・目撃した場合は、非公開の経路でメンテナにご連絡ください。[Security タブ](https://github.com/EndlessPixel-Studio/FakePlayer-CE/security) から非公開で報告するか、GitHub でメンテナに直接連絡してください。当事者を名指しする公開 issue は作成しないでください。

すべての報告は迅速かつ公正に審査・調査されます。メンテナは報告者のプライバシーと安全を尊重する義務を負います。

対応は次の 4 段階です。

1. **是正** — 問題点と期待される行動を非公開で伝え、必要に応じて公開での謝罪を求めます。
2. **警告** — 継続した場合の結果を伴う警告。関係者とのやり取りを一定期間禁止する場合があります。
3. **一時的な利用停止** — 一定期間、コミュニティでのあらゆる交流・公開コミュニケーションを禁止します。
4. **恒久的な利用停止** — コミュニティ内でのあらゆる公開の交流を永久に禁止します。

メンテナは、本規範に沿わないコメント、コミット、コード、issue その他の貢献を削除・編集・拒否する権利と責任を有し、必要に応じてその理由を説明します。
