# 快速開始

FakePlayer-CE 用於在伺服器端生成對伺服器完全透明的假人玩家，適用於區塊常駐載入與自動化。

## 安裝

1. 安裝 [CommandAPI](https://commandapi.jorel.dev) 到 `plugins/`。
2. 把插件 jar 放入 `plugins/`。
3. 啟動伺服器一次，把生成的 `config.tmpl.yml` 重新命名為 `config.yml`。
4. 執行 `/fp spawn`。

完整的指令與設定說明見專案 [README](https://github.com/EndlessPixel-Studio/FakePlayer-CE#readme)。
