# fp.build20 — 2026-11-20

## 新功能

- **`/fp autosleep on|off [假人]`**：假人夜里自动找空床睡觉，仅主世界生效，4 格内需要有空床。
- **支持 MySQL**：`database.type: mysql` + `database.mysql` 段；密码、UUID 映射、皮肤与个人配置可存入 MySQL；`/fp migrate-db` 从 SQLite 迁移。`config.yml` 版本 35。
- **假人支持重命名（#39）**：`/fp rename <名称> <新名称> [force]` 会迁移数据并按原位置/寿命/创建者重新召唤；占用名称默认拒绝，`force` 可接管。

## 改进与修复

- 命令帮助说明跟随玩家语言，不再固定为服务器语言（#142）。
- 假人移除后登录插件豁免标记一定会被清理（#143）。
- HTTP 管理接口改用 Undertow：单请求 URI 上限 4 KB、空闲连接 30 秒回收、优雅关闭。
- 「看向附近实体」会排除自己、正确比较距离并看向实体眼睛（上游 #129）。
- 发包重写不再把异常冒泡给第三方插件（#135 / PlayerPoints#75）。
