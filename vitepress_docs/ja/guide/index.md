# クイックスタート

FakePlayer-CE は、サーバーから見て完全に実際のプレイヤーとして扱われる偽プレイヤーを生成します。チャンクの読み込み維持や自動化に使えます。

## インストール

1. [CommandAPI](https://commandapi.jorel.dev) を `plugins/` に入れる。
2. プラグインの jar を `plugins/` に入れる。
3. サーバーを一度起動し、生成された `config.tmpl.yml` を `config.yml` にリネームする。
4. `/fp spawn` を実行する。

コマンドと設定の詳細はプロジェクトの [README](https://github.com/EndlessPixel-Studio/FakePlayer-CE#readme) を参照してください。
