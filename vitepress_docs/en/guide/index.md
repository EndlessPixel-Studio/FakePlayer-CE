# Quick start

FakePlayer-CE spawns fake players that appear fully real to the server, useful for keeping chunks loaded and for automation.

## Installation

1. Install [CommandAPI](https://commandapi.jorel.dev) into `plugins/`.
2. Put the plugin jar into `plugins/`.
3. Start the server once, then rename `config.tmpl.yml` to `config.yml`.
4. Run `/fp spawn`.

See the project [README](https://github.com/EndlessPixel-Studio/FakePlayer-CE#readme) for the full command and configuration reference.
