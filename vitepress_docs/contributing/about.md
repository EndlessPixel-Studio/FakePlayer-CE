# 关于 FakePlayer-CE

FakePlayer-CE 是一个社区维护的 Minecraft 假人插件，继承自 tanyaofei/minecraft-fakeplayer，并提供多版本支持、HTTP 管理接口、AI 聊天、灵活的配置与数据库后端。

## 名称与商标

"Minecraft" 与 "我的世界" 是 Mojang AB 的注册商标。本项目与 Mojang 或 Microsoft 无任何关联。

## 行为准则

所有 issue、PR、讨论与提交信息都适用行为准则：尊重他人、不骚扰、不人身攻击、不泄露他人隐私。违规内容可能被删除或拒绝，严重情况会限制参与。详见 `docs/CODE_OF_CONDUCT_zh.md`。
