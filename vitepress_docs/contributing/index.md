## 快速了解

- 项目使用 Java 25，Gradle 构建，本地验证以 CI 为准。
- 提交信息用英文前缀 + 中文描述，例如 `feat: 新增 xxx`、`fix: 修复 xxx`。
- CHANGELOG 中英条目数量与顺序必须一致，只写用户可感知的变化。
- 改 `config.yml` 必须把顶部 `version` 加 1。
- 面向用户的文案必须补齐五份 `message*.properties`（en/zh/zh_TW/zh_HK/ja）。

完整规则见仓库的 `docs/CONTRIBUTING_zh.md`。
